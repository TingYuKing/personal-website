# Taiyu Personal Brand Site

Vite + React + Tailwind CSS local preview project for the Taiyu personal brand React component.

## Local Preview

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. By default it is usually:

```text
http://localhost:5173
```

## Build

```bash
npm run build
```

## Commit To GitHub

If this folder is not a git repository yet:

```bash
git init
git add .
git commit -m "Create Vite React Tailwind personal site"
git branch -M main
git remote add origin https://github.com/YOUR_ACCOUNT/YOUR_REPO.git
git push -u origin main
```

If you already connected a remote repository:

